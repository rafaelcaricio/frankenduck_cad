## Adapted material: Microduck by Pollen Robotics

Frankenduck is an adaptation of the **Microduck** robot by
**Pollen Robotics**:

- 3D model files: https://github.com/pollen-robotics/microduck_rl
  (`src/mjlab_microduck/robot/microduck/assets/*.stl`), copyright Pollen
  Robotics, licensed under CC BY-NC-SA 4.0
  (https://creativecommons.org/licenses/by-nc-sa/4.0/).
- Robot software: https://github.com/pollen-robotics/microduck
  (Apache License 2.0). No code from this repository is included here.

The printed parts in this repository were derived from Pollen Robotics'
Microduck mesh files and then **modified**. The changes include: rebuilt
parametric part models, adaptation to Feetech STS3215 servos, horn-bearing
leg joints and passive leg supports, a revised neck and head, a Radxa Cubie A7Z
carrier, cooler and camera mounts, a LiPo battery holder and the trunk and
shell changes these parts require.
